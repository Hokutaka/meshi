# meshi

**meshi** は、Android ネイティブで動く個人用・完全ローカルファーストの家計簿アプリです。

> 記録は簡単に、データは厳密に。

金額とカテゴリーだけのクイック入力を基本に、必要な場合だけ購入明細や商品マスタを利用します。食事に限定せず、日用品・交通・趣味などの支出や収入を扱うことを目指します。

## 方針

- **Android ネイティブ**: Kotlin / Jetpack Compose / Material 3
- **オフライン専用**: アカウント、サーバー、広告、解析 SDK、クラウド同期なし
- **ローカル保存**: Room (SQLite) + SQLCipher を採用候補とする。実装前にバージョン互換性を検証
- **入力の粒度は任意**: 取引合計のみでも保存でき、あとから明細を追加できる
- **データの安全性**: Android Keystore を使う鍵保護、ユーザー操作による暗号化バックアップと復元
- **配布**: Google Play は使わず、GitHub Releases から署名済み APK を配布
- **公開するもの**: アプリのコード・設計・テスト・リリース成果物。個人の実データや署名秘密鍵は公開しない

**現在の状態:** 設計段階。アプリはまだ実装・配布されていません。暗号化や完全オフラインは現時点では実装済みの保証ではなく、実装・検証する要件です。

## 最初のスコープ

1. 金額・日付・カテゴリーによる取引の登録
2. 履歴表示、編集・削除、月間の集計
3. ローカルDBの暗号化と安全な鍵管理
4. 暗号化バックアップ、復元、DBマイグレーション
5. テストを通した署名済みAPKの GitHub Releases 配布

商品マスタ・明細・入力テンプレートはドメインモデルに拡張余地を残し、段階的に実装します。

## 開発予定のスタック

| 領域 | 採用方針 |
| --- | --- |
| UI | Kotlin + Jetpack Compose |
| 画面状態 | ViewModel + StateFlow |
| 永続化 | Room + SQLite |
| DB暗号化 | SQLCipher for Android（統合テスト必須） |
| 鍵の保護 | Android Keystore |
| ロック | BiometricPrompt / 端末認証 |
| 設定 | DataStore（非機密設定のみ） |
| CI | GitHub Actions |
| 配布 | 署名済み APK / GitHub Releases |

ライブラリの具体的なバージョンは Android プロジェクト作成時に検証・固定します。

## 開発時の重要事項

- 実際の取引、口座、購入履歴、レシート、暗号鍵、署名鍵をリポジトリにコミットしない
- リリースビルドの merged manifest に INTERNET 権限がないことを自動検査する
- アプリ更新・バックアップ復元後も既存データが失われないことをテストする
- セキュリティ設計と実装状況を混同しない
